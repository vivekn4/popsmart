# PROJECT BRIEF — Micro-Learning Companion (working title: "POPSMART")

## Vision
A hyper-personalized micro-learning web app: bite-sized interactive lessons,
skill checkpoints, and flashcards that adapt pacing automatically to the user's
focus metrics and habit rhythms.

## Design language
Neo-Brutalism & Sticker Pop:
- Raw layouts, thick black outlines (3-4px), hard offset shadows (no blur)
- Chunky sticker-like icons with white inner outline + black outer border
- High-energy color blocking: bright yellow (#FFE600), purple (#7C3AED),
  pink (#FF6B9D), off-white paper (#FFFDF5), black (#111)
- Bold, chunky typography (system stack, heavy weights)
- Playful, Gen-Z energy — stickers, badges, pops

## v1 Scope (MVP)
1. **Dashboard** — streak, today's focus score, habit rhythm chart (best study
   hours), skill progress rings
2. **Lessons** — bite-sized interactive cards (3-5 min each), 3 starter subjects
3. **Flashcards** — SM-2 spaced repetition, flip animation
4. **Checkpoints** — short quizzes gating skill levels
5. **Adaptive engine** — tracks accuracy, response time, session time-of-day;
   adjusts difficulty, session length, and review intervals automatically
6. **Habit rhythms** — learns when the user studies best, nudges accordingly

## Technical
- Static HTML/CSS/JS, zero dependencies, zero cost
- localStorage for all progress (no backend in v1)
- Mobile-first responsive, keyboard navigable
- GitHub Pages deployable (vivekn4)

## Quality bar
- Unanimous team green light before ship
- QA: all flows tested | A11y: keyboard + screen reader | Perf: <1s load
- Human-sounding copy, zero AI tells
